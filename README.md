# ربات حسابدار هوشمند «حساب‌یار» (HesabYar) 🚀

[![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/ramin-mahmoodi/HesabYar)

ربات حسابداری شخصی و دفترکل مالی هوشمند، مبتنی بر معماری **Edge Serverless** روی **Cloudflare Workers**.  
این ربات **کاملاً رایگان**، ۲۴ ساعته آنلاین و بدون نیاز به خرید سرور کار می‌کند.

---

## ✨ امکانات برجسته

- 📷 **استخراج هوشمند از عکس رسید:** ارسال تصویر رسید بانکی یا فاکتور و استخراج خودکار مبلغ، تاریخ، نوع و دسته‌بندی با **Cloudflare Workers AI (Llama 3.2 Vision)**.
- 🎙 **دستیار صوتی (Voice):** ارسال وویس و گفتن مخارج به زبان محاوره‌ای فارسی و تبدیل به متن با **Whisper** و ثبت هوشمند در حسابداری.
- ✉️ **تحلیل هوشمند پیامک بانکی:** فوروارد یا ارسال متن پیامک‌های بانکی جهت استخراج خودکار واریز/برداشت.
- 📊 **خروجی اکسل پیشرفته (`.xlsx`):** دانلود کارنامه مالی ماهانه در قالب فایل اکسل با دو برگه شامل خلاصه عملکرد و ریز تمام اسناد.
- 📈 **رسم نمودارهای تصویری (Charts):**
  - 🍩 نمودار دایره‌ای سهم هزینه‌ها به تفکیک دسته‌بندی
  - 📊 نمودار میله‌ای مقایسه‌ای درآمد و مخارج
- 💳 **دفترکل و حساب‌های بانکی:** ثبت کارت‌های مختلف، شماره شبا، موجودی اولیه و محاسبه مانده لحظه‌ای.
- 📅 **تقویم کاملاً شمسی:** تفکیک تراکنش‌ها و گزارش‌ها مطابق با تقویم جلالی.

## 🔑 توکن ربات تلگرام را کجا بگذاریم؟

شما می‌توانید توکن دریافتی از [@BotFather](https://t.me/BotFather) را به **یکی از دو روش زیر** تنظیم کنید:

### روش ۱: از طریق داشبورد کلادفلر (پیشنهادی و امن)
1. وارد پنل [Cloudflare Dashboard](https://dash.cloudflare.com/) شوید.
2. به بخش **Workers & Pages** رفته و روی ورکر `hesabyar-bot` کلیک کنید.
3. وارد تب **Settings** $\rightarrow$ **Variables and Secrets** شوید.
4. دکمه **Add** را بزنید:
   * **Variable name:** `BOT_TOKEN`
   * **Value:** توکن ربات تلگرامتان (مثلاً `123456789:ABCdefGHI...`)
5. دکمه **Save and Deploy** را بزنید.

### روش ۲: از طریق ترمینال با دستور Wrangler
```bash
npx wrangler secret put BOT_TOKEN
```
پس از زدن این دستور، توکن را Paste کرده و Enter بزنید.

> **نکته امنیتی:** اگر می‌خواهید ربات فقط به خودتان پاسخ دهد و غریبه‌ها نتوانند به حساب شما دسترسی داشته باشند، آی‌دی عددی تلگرام خود را در متغیر `ALLOWED_USER_IDS` قرار دهید (مثلاً: `12345678`).

## 🛠 راه‌اندازی سریع در کلادفلر (قدم‌به‌قدم)

### ۱. نصب وابستگی‌ها
```bash
npm install
```

### ۲. ساخت دیتابیس Cloudflare D1
در ترمینال دستور زیر را اجرا کنید:
```bash
npx wrangler d1 create hesabyar-db
```
پس از اجرا، کلادفلر یک `database_id` به شما می‌دهد. آن را در فایل `wrangler.toml` جلوی `database_id` جایگزین کنید:
```toml
[[d1_databases]]
binding = "DB"
database_name = "hesabyar-db"
database_id = "شناسه_دریافتی_اینجا"
```

### ۳. ساخت جدول‌های دیتابیس
```bash
# برای دیتابیس ابری کلادفلر:
npm run d1:init:prod
```

### ۴. انتشار (Deploy) ورکر
```bash
npm run deploy
```
پس از چند ثانیه، کلادفلر آدرس ورکر شما را نمایش می‌دهد:
`https://hesabyar-bot.<نام-کاربری-شما>.workers.dev`

### ۵. تنظیم وب‌هوک تلگرام (فقط با باز کردن این لینک در مرورگر)
آدرس زیر را با مشخصات خود در مرورگر باز کنید تا تلگرام به ورکر متصل شود:
```text
https://api.telegram.org/bot<توکن_ربات>/setWebhook?url=https://hesabyar-bot.<نام-کاربری-شما>.workers.dev
```
اگر پیغام `{"ok":true,"result":true,"description":"Webhook was set"}` را دیدید، ربات شما ۲۴ ساعته آنلاین و آماده کار است! 🎉

## ⌨️ دستورات ربات

| دستور | عملکرد |
|---|---|
| `/start` | راه‌اندازی و نمایش منوی اصلی |
| `/help` | راهنمای کامل استفاده از قابلیت‌ها |
| `/report` | خلاصه وضعیت ماه جاری + دکمه‌های اکسل و نمودار |
| `/accounts` | لیست کارت‌ها، حساب‌ها و موجودی لحظه‌ای |
| `/newaccount` | افزودن حساب یا کارت جدید |
| `/deposit` | ثبت دستی واریز (درآمد) |
| `/withdraw` | ثبت دستی برداشت (خرج) |
