# ربات حسابدار هوشمند «حساب‌یار» (HesabYar) 🚀

[![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/ramin-mahmoodi/HesabYar)

**حساب‌یار** یک دستیار هوشمند مالی و حسابداری شخصی مبتنی بر تلگرام است که بر روی زیرساخت کاملاً ابری و سرورلس **Cloudflare Workers** اجرا می‌شود.  
این پروژه از هوش مصنوعی قدرتمند **Google Gemini** برای استخراج رسیدها و صوت‌های فارسی استفاده می‌کند و بدون نیاز به خرید هاست یا سرور اختصاصی، به صورت **۲۴ ساعته و ۱۰۰٪ رایگان** آنلاین است.

---

## ✨ امکانات برجسته

- 🔘 **ثبت مرحله‌به‌مرحله با دکمه‌های شیشه‌ای (Inline Keyboards):**
  - ثبت بسیار ساده و منظم دخل و خرج: ورود مبلغ دستی $\rightarrow$ انتخاب دسته‌بندی با دکمه شیشه‌ای $\rightarrow$ انتخاب حساب بانکی با دکمه شیشه‌ای $\rightarrow$ تایید نهایی.
  - پشتیبانی هوشمند از انواع فرمت‌های مبلغ (فارسی، انگلیسی، کاما، پسوند «هزار»، «میلیون»، «تومان» و «ریال»).
- 📷 **استخراج هوشمند رسید و فاکتور:**
  - ارسال عکس رسید بانکی یا فاکتور خرید و تشخیص خودکار مبلغ، تاریخ، نوع (واریز/برداشت) و دسته‌بندی توسط **Google Gemini Flash**.
- 🎙 **دستیار صوتی پیشرفته (Voice):**
  - فقط کافیست وویس بفرستید و خرجتان را به فارسی محاوره‌ای بگویید (مثلاً: *«امروز ۵۰ تومن دادم بنزین زدم»*) تا صوت توسط Gemini گوش داده شده و سند مالی آن آماده تایید شود.
- ✉️ **تحلیل خودکار پیامک‌های بانکی:**
  - فوروارد یا چسباندن متن پیامک تراکنش بانک و تشخیص خودکار واریز، برداشت، مبلغ و موضوع تراکنش.
- 💳 **مدیریت حساب‌ها و کارت‌های بانکی:**
  - افزودن آسان حساب با انتخاب بانک‌های کشور (ملت، ملی، صادرات، پاسارگاد، سامان، بلوبانک، سپه، تجارت، آینده، رسالت و...).
  - نگهداری موجودی اولیه و محاسبه لحظه‌ای مانده واقعی هر حساب.
- 📊 **گزارش‌گیری ماهانه با خروجی اکسل (`.xlsx`):**
  - دانلود کارنامه مالی ماه در قالب یک فایل اکسل ۲ برگه‌ای (خلاصه عملکرد ماهانه + ریز تمام اسناد).
- 📈 **رسم نمودارهای گرافیکی زیبا:**
  - 🍩 نمودار دایره‌ای تفکیک هزینه‌ها به ازای هر دسته‌بندی.
  - 📊 نمودار میله‌ای مقایسه‌ای دخل و خرج ماهانه.
- 📅 **تقویم ۱۰۰٪ جلالی (شمسی):**
  - تفکیک گزارش‌ها و اسناد بر اساس ماه‌های تقویم ایرانی.
- 🔒 **حریم خصوصی و امنیت بالا:**
  - امکان تعریف `ALLOWED_USER_IDS` جهت محدودسازی ربات فقط به آی‌دی تلگرام خودتان.

## 🔑 متغیرهای محیطی مورد نیاز (Environment Secrets)

| نام متغیر | نوع | توضیحات |
|---|---|---|
| `BOT_TOKEN` | الزامی (Secret) | توکن ربات دریافتی از [@BotFather](https://t.me/BotFather) |
| `GEMINI_API_KEY` | الزامی (Secret) | کلید رایگان Google Gemini API از [Google AI Studio](https://aistudio.google.com/) |
| `ALLOWED_USER_IDS` | اختیاری (Secret) | شناسه(های) عددی کاربر مجاز در تلگرام جهت امنیت (مثلاً: `12345678`) |
| `DEFAULT_ACCOUNT_NAME` | اختیاری | نام حساب پیش‌فرض (پیش‌فرض: `حساب اصلی`) |

## ⚙️ راه‌اندازی و استقرار روی Cloudflare Workers

### روش اول: استقرار خودکار با دکمه Deploy (ساده‌ترین روش)

1. روی دکمه **Deploy to Cloudflare Workers** در بالای صفحه کلیک کنید.
2. وارد حساب Cloudflare و GitHub خود شوید و اجازه دسترسی را صادر کنید.
3. کلادفلر یک ریپازیتوری جدید در گیت‌هاب شما می‌سازد و دیتابیس D1 را می‌سازد.
4. وارد داشبورد کلادفلر شوید:
   - به مسیر **Workers & Pages** $\rightarrow$ **hesabyar-bot** $\rightarrow$ **Settings** $\rightarrow$ **Variables and Secrets** بروید.
   - دو متغیر زیر را اضافه کرده و دکمه **Encrypt** را فعال کنید:
     - `BOT_TOKEN`: توکن ربات تلگرام شما
     - `GEMINI_API_KEY`: کلید دریافتی از Google AI Studio
   - در صورت تمایل `ALLOWED_USER_IDS` را نیز جهت حفظ حریم خصوصی اضافه کنید.
   - دکمه **Save and Deploy** را بزنید.
5. لینک وب‌هوک تلگرام را یک‌بار در مرورگر باز کنید (طبق مرحله وب‌هوک در ادامه).

---

### روش دوم: راه‌اندازی دستی از طریق ترمینال (CLI)

#### ۱. نصب وابستگی‌ها
```bash
npm install
```

#### ۲. ساخت دیتابیس Cloudflare D1
```bash
npx wrangler d1 create hesabyar-db
```
شناسه `database_id` نمایش داده شده را در فایل `wrangler.toml` کپی کنید:
```toml
[[d1_databases]]
binding = "DB"
database_name = "hesabyar-db"
database_id = "شناسه-دریافتی-شما"
```

#### ۳. ساخت جدول‌های دیتابیس در کلادفلر
```bash
npm run d1:init:prod
```

#### ۴. ثبت کلیدها در Secrets کلادفلر
```bash
npx wrangler secret put BOT_TOKEN
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put ALLOWED_USER_IDS # اختیاری
```

#### ۵. انتشار روی کلادفلر
```bash
npm run deploy
```
آدرس اختصاصی ورکر شما به این صورت نمایش داده می‌شود:
`https://hesabyar-bot.<نام-کاربری>.workers.dev`

---

### ۶. فعال‌سازی وب‌هوک تلگرام

تنها کافی است این لینک را یک بار در مرورگر خود باز کنید:
```text
https://api.telegram.org/bot<توکن_ربات_شما>/setWebhook?url=https://hesabyar-bot.<نام-کاربری-ورکر>.workers.dev
```

مشاهده پیام زیر یعنی وب‌هوک با موفقیت ست شده و ربات آماده استفاده است:
```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

## ⌨️ دستورات و کلیدهای ربات

| دستور | کلید معادل در کیبورد | عملکرد |
|---|---|---|
| `/start` | - | راه‌اندازی مجدد و نمایش منوی اصلی ربات |
| `/withdraw` | ➖ ثبت برداشت (خرج) | آغاز ثبت مرحله‌به‌مرحله هزینه با دکمه‌های شیشه‌ای |
| `/deposit` | ➕ ثبت واریز (درآمد) | آغاز ثبت مرحله‌به‌مرحله درآمد با دکمه‌های شیشه‌ای |
| `/accounts` | 💳 حساب‌ها و کارت‌ها | نمایش مانده حساب‌ها و دکمه شیشه‌ای افزودن حساب جدید |
| `/newaccount` | ➕ افزودن حساب جدید | ویزارد ثبت حساب جدید (انتخاب بانک، موجودی و کارت) |
| `/report` | 📊 گزارش ماه جاری | نمایش خلاصه دخل و خرج ماه + دکمه دانلود اکسل و نمودار |
| `/cancel` | ❌ انصراف | لغو مرحله جاری و بازگشت به حالت عادی |
| `/help` | - | راهنمای کامل نحوه استفاده از امکانات |

## 🛠 فناوری‌های استفاده شده

- **Runtime:** [Cloudflare Workers](https://workers.cloudflare.com/) (Edge V8 Serverless)
- **Language:** TypeScript
- **Bot Framework:** [grammY](https://grammy.dev/)
- **Database:** [Cloudflare D1](https://developers.cloudflare.com/d1/) (SQLite distributed at the edge)
- **AI Multimodal Engine:** [Google Gemini API](https://ai.google.dev/) (`gemini-flash-latest`)
- **Calendar:** [jalaali-js](https://github.com/jalaali/jalaali-js)
- **Excel Export:** [SheetJS (xlsx)](https://sheetjs.com/)
- **Charts:** [QuickChart](https://quickchart.io/)
